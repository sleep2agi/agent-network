# v0.10.10 — 小米 MiMo 5 模型完整支持 + envRef 自动衔接

## 🌟 Highlights

### 小米 MiMo Vendor Preset 完整

- ✅ 新增 `mimo-v2.5-tts-voicedesign` 模型，凑齐官方 5 个模型
- ✅ `anet node create` 选择 `claude-agent-sdk` runtime → 「小米 MiMo」vendor → 5 个模型任选：`mimo-v2.5-pro`（默认）/ `mimo-v2.5` / `mimo-v2-pro` / `mimo-v2-omni` / `mimo-v2.5-tts-voicedesign`
- ✅ endpoint `https://token-plan-cn.xiaomimimo.com/anthropic` 完整对接 Anthropic Messages 协议
- 📌 注：`voicedesign` 模型是 TTS 语音设计模型，Anthropic Messages 文本请求大概率 vendor 不支持；文本对话请用前 4 个模型

### envRef wizard-to-start 自动衔接（#193）

**原来的痛点**：`anet node create` 完后，同一个 shell 立即跑 `anet node start` 会报 FATAL `env var not set`，必须手动 `export ANTHROPIC_AUTH_TOKEN_N_<id>=...` 才能起。

**现在的行为**：

- ✅ wizard create 时 API key 自动写入 `.anet/nodes/<alias>/.env` 文件（mode 0600，自动加入 `.anet/.gitignore`）
- ✅ `anet node start` 启动前自动 source 该 `.env` 文件，无需手动 export
- ✅ 跨机部署仍支持：wizard 仍 print 一次 export 命令，用户可手动 copy 到另一台机
- ✅ Debug 日志只输出 `loaded N key(s) from .anet/nodes/<alias>/.env`，不 echo key 值
- ✅ 向后兼容：已有 `ANTHROPIC_AUTH_TOKEN_N_*` 在 shell 中 export 的继续 work；老节点的 plain `config.json` 模式也继续 work

适用所有 `claude-agent-sdk` 类型节点（MiMo / MiniMax / 书生 / GLM / 任意 Anthropic Messages 兼容 vendor）。

## 🐛 Bugs Fixed

- **#192** `anet -v` 不显示完整 prerelease 后缀：已修，现在显示 `v2.2.9` 完整版本号（含 `-preview.N` 后缀 when applicable）
- **#189 Grok runtime** `grok-build-acp` 全面稳定化：explicit delegation parser broaden 全 case 覆盖（含 "你和 X 沟通一下…"、"send_task X 一下…" 等无标点尾随 body 句式），跨节点 delegation 路由可靠
