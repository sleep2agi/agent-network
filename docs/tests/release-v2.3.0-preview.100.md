## 本版为什么值得单独发

本包的 `dist/` 是逐文件、未混淆、**带 `.d.ts`** 的输出 —— 源码里的文档注释会原样进类型声明并随包出货。`.97`/`.98`/`.99` 的声明文件里含有合作团队的节点别名(逐版去重后 9 / 9 / 11 处,全在 `.d.ts`;按「别名模式命中 + 裸团队名」两个重叠集合相加则为 10 / 10 / 12;同一 tarball 的非 `.d.ts` 输出 0 处)。**这一类只经类型声明泄漏**,仓树 grep 抓不全,只有 diff 打包树才找得齐。

本版是第一个打包声明干净的版本:对改后的树 `tsc --emitDeclarationOnly` ⇒ 117 个 `.d.ts`、0 命中(含裸团队名与带空格写法)。替换风格是**去身份、留归因**:日期、issue 号、测到什么全部保留,只去掉身份;夹具用明显合成的名字。

另一处:#1934 的索引加固 —— 索引文件名是规范化目录的哈希,不可逆,「推导出节点目录」这个选项不存在;记录缺 `node_dir` 时**跳过而不当身份**,文件保留不删(读不懂 ≠ 已证死);此类节点仍会被兄弟扫描看到。

## Install

```bash
npm i -g @sleep2agi/agent-network@2.3.0-preview.100
```

## Upgrade

```bash
npm i -g @sleep2agi/agent-network@2.3.0-preview.100 @sleep2agi/agent-node@2.5.0-preview.76
```

🔴 **两个包要一起升。** 配对是精确的(`.100 ↔ .76`);codex 队列那条修复(#1939)在 `agent-node` 里,本包不含。

## 边界与证据

- `tsc --noEmit` rc=0;parity 门(两个包里逐字节相同的模块)仍绿;doc-symbol-pins 两种 CI 参数形式与 doc-source-pins 全 rc=0;`home-path-baseline` rc=0。
- 保留且明说的:`TMWork小助手`(我们自己手工起的飞书 bot;19/21 处是 `docker exec`/`--alias`/路径里的承重键)与我们自己的节点名(`通信龙`/`通信牛`;后者另有 8 处在混淆 bundle 里是**字符串字面量**,改注释对其无效,属 #1933 的独立改动)。

## 披露

`2.3.0-preview.97` 至 `.99`(配对 agent-node `.73`–`.75`)的 `dist/src/*.d.ts` 注释中含有合作团队的节点别名;本版起已改为中性表述。旧版本**不撤包**:撤包会打断所有钉了版本的使用者,代价大于暴露面。
