per-node profile Hub, real task/SDK reply sourced from model HTTP and accepted
stop ACK. Checks actual HOME config after registration, reply and stop, requiring
byte equality or absence. Original unrelated cloud sentinel remains additional
write evidence only; no claim of complete read isolation.
