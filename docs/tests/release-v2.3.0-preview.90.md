# `@sleep2agi/agent-network@2.3.0-preview.90`

## 为什么发这一版:配对 agent-node `.69`(同日成对规则)

`.89` 之后 `agent-network/bin|src` 没有功能提交;本版只把配对版本推到 agent-node `.69`(#1869 回复本机文件链接自动上传成附件),让 `anet node create` 装到带修复的 agent-node,并让 published-pins 门与 main 一致。

| 用户看到的 | `.89` | `.90` |
|---|---|---|
| `anet node create` 配对装的 agent-node | `.68` | `.69` |

## Install

```bash
npm i -g @sleep2agi/agent-network@2.3.0-preview.90
```

## Upgrade

```bash
npm i -g @sleep2agi/agent-network@2.3.0-preview.90
```

## 边界

- anet 自身行为与 `.89` 逐字相同;不需要重启节点。
