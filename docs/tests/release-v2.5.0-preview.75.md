## 🔴 要这个功能的人,要的是这一版,不是 `.97`/`.98`

这道护栏走到本版一共修了三次,每次都是「已发布、但对真实机群无效」:

| 版本 | 做了什么 | 为什么还不够 |
|---|---|---|
| `.97`/`.73` | 实现了检测 | 调用点全在 `anet node start --copresence` 路径上 ⇒ 对**直接起 runtime 的 31/35 台**完全不触发 |
| `.98`/`.74` | 下沉到 `agent-node`,所有启动路径都会跑;并按「这份凭据还在不在被刷新」分支文案 | 比较的仍然是 `dirname(nodeDir)` 下的**兄弟节点** |
| **`.75`/`.99`(本版)** | 比较改成**主机级** | — |

**取集错在哪**:参照机群 35 台节点散在 **27 个 workspace**,其中 **25 个只装 1 台**。三条真实共享链一共 8 台,兄弟扫描只看得见**2 台**(恰好同一个 workspace 的那一对);而最需要确认的那组 —— 三台 `auth.json` **整文件字节全等**的节点 —— 分属三个不同 workspace,**整组漏掉**。

判据没错,**收集范围看不见要判的对象**。而它的失败形态是**沉默**:不报错、不告警,和「确实没有冲突」逐字同形。

## 本版怎么做的

- 节点除了写自己目录里那份,再往**主机级索引**发布一份:`~/.anet/codex-auth-fingerprints/`(目录 0700、文件 0600),文件名 = **规范化节点目录路径的哈希**。读方枚举这个索引,两个来源按规范化节点目录去重。
- **为什么不用 alias 当文件名**:alias 跨 workspace 不保证唯一,重名会互相覆盖 —— 那等于把本版正在修的盲区重新造一遍。**也不用 `node_id`**:agent-node 侧在旧配置上可能为空、需要兜底,于是**同一个节点**经 CLI 起和直接起会写出两个文件名,看起来像「两台节点共用一份凭据」的假阳性。`node_id` 仍记在记录内容里供人看。自我排除也从 alias 改成按节点目录。
- 🔴 **陈旧判据用「存在」不用「年龄」**:中心索引里的记录会比节点活得久,陈旧记录会产生**假告警**,而假告警比沉默更坏 —— 它训练人忽略这个告警。记录里存 `node_dir`,读时 `stat`;目录没了就跳过该记录**并删掉索引项**。年龄**从不**参与过滤,只在超过 7 天时附注一句。
  理由来自现场数据:最严重那组三台里有**两台根本没在跑**,29 份凭据里 **6 份数天没被动过** —— 而它们**仍然持有**共享凭据。按年龄截断,正好会把最值得报的冲突藏起来。

```bash
npm i -g @sleep2agi/agent-network@2.3.0-preview.99 @sleep2agi/agent-node@2.5.0-preview.75
```

🔴 **两个包要一起升。** 实现是一份**逐字节相同**的模块同时存在于两个包里(有 parity 门钉着),两条启动路径各用各的那份 —— 只升一个,另一条路径上的节点仍是旧行为。

## 证据

- **主判据 = 跨 workspace 那一格**:两台节点在**不同** workspace 根下共用同一份凭据 ⇒ 必须互相点名。对着修复前的模块跑,这条测试失败且**输出为零** —— 与生产里的症状一致:症状是沉默,不是报错。修复后输出 `<node-b> shares its codex login with: <node-a>`(夹具别名);把修好的模块换回去即转绿。
- 同 workspace 的那一对仍然能检出;凭据不同**一行都不打**;记录指向的节点目录已消失 ⇒ 不告警**且**该索引项被删除;节点目录还在但记录很旧 ⇒ **仍然告警**。
- parity 门同样两向见证:给副本追加一个字节 ⇒ 红,恢复 ⇒ 绿。
- agent-node 全套 1865 pass / 0 fail;typecheck 棘轮 81 = 基线;6 处 `tests/*/run.sh` 的 sed 锚仍全部命中。
- 🔴 两格自曝:① 读方变成主机级之后,测试会写进**真实的** `~/.anet`,且几个共用夹具名的用例会跨临时根互相匹配 —— 把断言「应当沉默」的用例弄红;已改成 hermetic,事后确认 `~/.anet/codex-auth-fingerprints` 不存在。② `home-path-baseline` 拒了我第一版夹具里写死的用户家目录字面量(本仓是公开仓);没有抬基线,而是去掉了那些字面量,并给「不泄漏」那条断言补了**阳性对照** —— 否则夹具里少写一个密文会让 `not.toContain(...)` 空转通过,而空转通过与真通过逐字同形。
