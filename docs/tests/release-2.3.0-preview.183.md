# agent-network 2.3.0-preview.183

配对版本：`PAIRED_AGENT_NETWORK_VERSION` → `2.3.0-preview.183`，`PAIRED_AGENT_NODE_VERSION` → `2.5.0-preview.147`。本版让 `anet` 解析到会把 OpenCode V2 会话模型回写到客户端的 agent-node。

## Install

```bash
npm install -g @sleep2agi/agent-network@2.3.0-preview.183
```

## Upgrade

```bash
npm install -g @sleep2agi/agent-network@2.3.0-preview.183 @sleep2agi/agent-node@2.5.0-preview.147
```

升完后只重启要生效的 OpenCode V2 节点。不要停共享 OpenCode 服务，也不要连带重启无关节点。
