命令：

```bash
sg docker -c 'docker build -t agent-orchestra-test26 -f tests/test26-network-scope/Dockerfile .'
sg docker -c 'docker run --rm agent-orchestra-test26'
```

## 结果

20 passed, 0 failed

## 覆盖点

- REST `/api/status` 无 token 返回 401。
- 非 admin 用户 `utok_` 默认只能看到自己所属 network 的 sessions。
- MCP `ntok_` 调 `report_status` 后，session 绑定到 token network。
- `send_task` / `get_inbox` 不允许跨 network 用同 alias 读取 inbox。
- `broadcast` 只进入 token 绑定 network，不泄漏到其他 network。
- `report_completion` 写入 `network_id`，`/api/completions` 按用户 network 隔离。
- `/api/messages` 按用户 network 隔离。
- viewer 不能创建 full-access network token。
- viewer 不能通过 REST `/api/task` 写入 viewer network。
- `agent-network/bin/cli.ts` 在 Docker 内完成 Bun build 语法检查。
