# agent-node — 五处修复一起上：切模型不卡死、402 说人话、报出自己怎么连 Hub、忙时告诉你等了多久

v2.5.0-preview.152 把五个修复放进同一版。其中两个直接改变节点在异常时的**行为**，三个改变它**报告什么**。

## 行为变化

**切 OpenCode V2 模型有 45 秒硬上限。** 换成一个这台机器上并不存在的模型时，节点以前会一直等下去 —— 表现为节点「在跑」但什么也不产出。现在最多等 45 秒就失败，并说明是模型在这台机器上不可用。客户端也会提醒：当前模型不在这台机器上报的列表里。

**共享会话忙到预算用完时，文案说清楚到底发生了什么。** 以前只报「超时」，看着像节点卡死；现在说的是：共享会话忙，30 分钟内未获提交 —— 这段时间共享会话一直被 TUI 里的一轮占着（不是节点卡死）。等待预算本身没有变，仍然是 30 分钟，也没有改成排队。

## 报告内容的变化

- 节点会报出自己是怎么连 Hub 的（loopback / https / plain），Hub 侧据此判断传输闸门。
- 共享会话忙时，每 30 秒报一次「已等多久」，不再长时间无声。
- 账号额度耗尽（grok 返回 402）时，节点说人话，不再甩一串 JSON。

## Install

```bash
npm install -g @sleep2agi/agent-node@2.5.0-preview.152
```

用你要替换的那个节点同一份 Hub 与网络令牌，不要复制别的节点的 `config.json`。

## Upgrade

```bash
anet upgrade
```

或者把上面的版本装进这个节点自己的前缀，等它空闲时再重启这个节点。重启会丢掉该节点上正在进行的一轮对话。这一版不会替你重启任何节点。

停留在 2.5.0-preview.151 或更早的节点，行为保持原样：切模型仍可能一直等，busy 仍是原来的文案。
