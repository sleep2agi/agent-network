WINDIR discrepancy is between two distinct layers, not a single env object:
product_env logs the JS builder output; received_process_env/helper logs the
spawned Node child's process.env. The native setup log identifies Node v22.23.4.
Its bundled libuv required_vars includes WINDIR, and make_program_env uses
GetEnvironmentVariableW to supplement missing required keys from the parent:
https://github.com/nodejs/node/blob/v22.23.4/deps/uv/src/win/process.c
This explains false in the builder / true after Node spawn. PSModulePath is
not in that required list. The fixture now logs received_process_env and actual
Node version explicitly (only key-presence booleans, never env values).
No product env allowlist expansion was made to hide the discrepancy.
