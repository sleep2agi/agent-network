# agent-network 2.3.0-preview.126

Pairing-only release: no behaviour change in `anet` since `2.3.0-preview.125`.

- `PAIRED_AGENT_NETWORK_VERSION` → `2.3.0-preview.126`, `PAIRED_AGENT_NODE_VERSION` → `2.5.0-preview.97` (see `release-v2.5.0-preview.97.md`), so codex co-presence and `opencode-cli` resolve agent-node `.97`.

## Install

```bash
npm i -g @sleep2agi/agent-network@2.3.0-preview.126 @sleep2agi/agent-node@2.5.0-preview.97
```

## Upgrade

```bash
npm i -g @sleep2agi/agent-network@2.3.0-preview.126 @sleep2agi/agent-node@2.5.0-preview.97
```

Upgrade both packages together.
