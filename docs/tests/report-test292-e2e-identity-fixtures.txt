## Verified behavior

- every simulated agent identity write uses a CLI-created config containing a
  stable `node_id` and Hub-issued, network-bound `ntok_`;
- the helper overwrites caller-supplied report identity with the config-bound
  alias and node ID;
- user tokens cannot impersonate an agent through `report_status`;
- inbox read, acknowledgement, status, and terminal reply complete under the
  node token, and inventory stores the exact stable node ID;
- concurrency, retry, cancel, reassign, expiration, stop/offline, and full mock
  lifecycle paths use authoritative fixtures rather than owner-token identity
  writes;
- legacy master-token MCP rejection and both anonymous health assertions match
  the real Hub transport contract;
- the free-user isolation fixture uses registration's default network plus one
  created network, registers one target in each, and proves both positive
  visibility and negative cross-network isolation;
- removed `quickstart` exits non-zero with migration guidance and creates no
  agent state.
