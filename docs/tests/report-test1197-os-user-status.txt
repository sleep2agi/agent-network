# test1197 — authoritative OS user status projection

Date: 2026-08-26
Base: `aca3a926` (`origin/main`)
Scope: issue #1197; no merge, package publish, deployment, or release.

## Contract

- `agent-node` and the production legacy `agent-network/src/node-server.ts`
  reporter read only `os.userInfo().username`.
- Collection failures, missing usernames, empty values, control characters, and
  values longer than 256 characters become `null`; there is no environment or
  `project_dir` fallback.
- `report_status.os_user` is nullable and bounded. Explicit `null` clears a
  previously reported identity; omission by an old reporter remains compatible.
- The Hub stores `sessions.os_user`. Authenticated, network-scoped full
  `/api/status` and scoped MCP status expose it. `/api/status?light=1` keeps its
  narrow list projection and intentionally omits the identity field.
