③ Step 2 Model 下拉 grey 掉所选 daemon 探测不到的 provider 对应 model — 直接答 Vincent「不同服务器网络环境不一样」(§9.5 D6: providers.reachable_from_daemons jsonb, RFC-028 probe 同步 upsert)。
④ Step 2 Secrets grey 掉所选 daemon 不在 allowed_secret_keys 列表的 key (§9.3 D5: per-daemon env allowlist, daemon-side validate-on-pull 兜底, 仍可拒 daemon_env_key_missing)。
⑤ 三态切换: count=0 → 替换整 wizard 成空状态 + 装 daemon 命令; count=1 → 自动选第一个 + skip Step 1 直接 Step 2 (保 P1 quick path); count≥2 → 必选 Step 1 (本图所示)。详 §9.4。
⑥ 失败兜底: 选 daemon 后 mid-dispatch offline → hub fail-fast + sweeper revoke; daemon 声明 runtime 但 spawn 挂 → runtime_capability_check_failed 显式报错。详 §9.6。
