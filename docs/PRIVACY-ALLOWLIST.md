# 公开仓的活体标识:允许清单与扫描判据

本仓是公开仓。**外部团队**的节点别名、主机名、内网地址不得出现在任何会公开的载体里 —— 仓树(含注释)、
已发布的 npm 产物(含 `.d.ts`)、issue 与评论。背景与全部读数见 #1933。

## 为什么要有这份清单

2026-09-20 的清理(#1936、#1941)之后,一次全树复扫**差点把下面这些当成残留报上来**。没有这份清单,
下一轮换个人再扫一次,同样的误报会重演;有了它,「0 命中」才有可审的定义。

## 扫描判据(外部复核方给的,两向验证过)

```
(?<![A-Za-z])TM[A-Za-z]{0,12}[ \t]?[一-龥]
```

- `(?<![A-Za-z])` 避开 `HTML` / `TMPDIR` / `TEMPLATE` 的尾缀误报;
- 允许**一个空格**,抓住 `TMCode 负责人` 这种带空格写法(#1936 按无空格形扫,漏了它,#1941 补);
- 命中后**减去本清单**,剩余即真残留。

## 三类载体,三种命运(一次 grep 仓树抓不全)

| 载体 | 生成方式 | 命运 |
|---|---|---|
| 文档注释(`/** … */`) | `tsc` 编译进 `dist/src/*.d.ts` | **随 `agent-network` 包出货**(`files: ["dist"]`) |
| 普通注释 | 单文件 bundle | `agent-node` 的 `dist/cli.js` 剥掉;`agent-network` 的逐文件 `dist` 保留 |
| 字符串字面量 | 进运行时 `.js` | 两个包都出货;混淆后按名字 grep 会**假阴性**,要找可见报错串或 `.d.ts` |

⇒ **验收判据 = `npm pack` 解出的树**(重点 `.d.ts`),不是仓树。已发布的 `.97`–`.99` 里含外部团队别名共 32 处
(各 10 / 10 / 12),**不 unpublish**(撤包打断所有钉版本的使用者),从 `.100` 起产物干净。

## 纪律

引用外部团队的现场读数时,在进入任何公开载体**之前**就替换成占位:节点 → `node-a`/`节点甲`,工作区 → `ws-NN`,
指纹组 → `fp-NN`。**结构才是论据**(几组、每组几台、跨几个工作区),名字不是。发完 issue / PR / notes **回读一次**。
