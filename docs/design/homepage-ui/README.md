# anet.sh 首页改版方案 · 第一版（仅评审）

基于 agent-network main `6a20bde2`，2026-09-29。**不是已上线页面，也不是待直接部署的 VitePress 替换件。** 本分支只加方案、独立 HTML 原型、截图和小型浏览器检查，不修改 docs-site 的现有入口、配置或部署。

## 建议方向：把工作台放到舞台中央

保留现有「让 AI Agent 组成团队」定位，视觉改为浅暖底色、深绿强调、清晰文字层次；用真实产品界面代替大面积背景特效。不是重做品牌，原型左上角字母徽记仅为排版占位，落地应复用现有品牌资产。

当前 main 已经有真实聊天截图，也已经有国内/GitHub 双下载线路。本方案**不把这两项说成新功能**。现状问题在信息顺序：默认 VitePress hero、功能卡、桌面下载、移动下载、两条入门路径和末尾 CTA 内容重叠，截图仍是历史聊天页，任务协作难以被初访者发现。

### 信息顺序

1. 首屏回答「是什么、能帮我做什么、从哪开始」：主标题 + 两句说明 + 下载主按钮 / 文档次入口。
2. 一个产品展示区：任务协作 / Agent 对话切换。桌面展示三列看板；手机使用真实窄屏截图局部，不把桌面图缩成不可读缩略图。
3. 三步说明：连接 Agent → 给工作绑定负责人 → 查看并维护进度。注明人员绑定不等于自动派单。
4. 一个下载区：macOS / Windows / 移动端。保留国内镜像和 GitHub；iOS 独立标记实际开放状态，不让人误以为有现成下载。
5. CLI 放在下载区下方作为开发者分支；最后说明自托管与数据控制，页尾保留 SkillHub / API / 社区 / English / 版本记录。

### 视觉与交互

- 桌面内容宽1200px，1440px视口两侧各120px；手机390px两侧22px。
- 正文墨绿 `#19312e`，主操作 `#116c58`，页面 `#f7f8f3`。不新增动画依赖，不做自动轮播。
- 主按钮高度48px；产品 tabs 支持方向键/Home/End；焦点可见、跳过导航、减少动态偏好。
- 下载按钮不猜用户系统、不触发自动下载；原型跳到现有官网的下载选择区。正式落地需在本站卡片中保留现有两条真实下载链接，不多加一次跳转。
- 首屏不写浮动版本号/文件大小/在线节点计数。下载区实施时复用发布元数据，与包平台一一对应，绝不把旧版本标成最新。
- 本轮只评审浅色中文方向；英文/深色、搜索与完整 VitePress 导航在落地轮复用已有能力，**不能因此删除原有切换入口**。

## 复现评审截图

仓库根目录执行（只在 Docker 内安装依赖、开临时静态服务）：

```sh
sg docker -c 'docker build -f tests/test-homepage-proposal/Dockerfile -t anet-homepage-proposal:review .'
mkdir -p /tmp/anet-homepage-review
sg docker -c 'docker run --rm --ipc=host -v /tmp/anet-homepage-review:/output anet-homepage-proposal:review'
```

也可在浏览器直接打开本目录 `index.html` 查看原型。无常驻服务、无生产端口、无环境变量/密钥、无用户数据、无数据库；仅静态评审文件，切换/回滚就是选择或移除本设计提交，不涉及运行服务。截图环境使用 Noto Sans CJK 字体。
