# 任务标签

给一张任务卡片贴上短标签，用来在列表里认出来，也可以按一个标签筛选。Hub 0.9.0-preview.68 起可以保存。客户端从 0.2.151 起有界面。更早的 Hub 没有 `tags` 字段时，详情里不提供输入，并提示升级，不会把标签假装存上。

字段和错误以 [需求池 / 任务看板](/api/mcp-tools#需求池-任务看板) 为准。

## 在客户端里

在详情里输入一个新标签，或从已有标签里点一个。点标签上的 × 去掉。看板卡片和列表的标题下面会显示这些标签。

桌面在左侧按标签筛选，手机在顶栏。一次只选一个，必须和标签全文一致，并与状态、项目等其他筛选同时生效。筛选项来自当前列表里已经载入的卡片。换网络后筛选回到「全部」。

iOS 仍走 TestFlight，公开链接还没开。

## 保存规则

`tags` 是字符串数组。

- 最多 10 个。每个最多 20 个字，按 Unicode 码位计数，不是 UTF-16。
- 去掉首尾空格。重复的只留第一次。空字符串和控制字符会被拒绝。
- 不合法时返回 400 `invalid_tags`，原来的标签不变。
- 新建时不带 `tags`，就是空数组。
- 修改时不带 `tags`，保持原样。带上 `[]` 会清空。

节点令牌可以在它绑定的网络里读写任务上的标签。viewer 只能看，不能改。

`GET /api/requirements/tags` 返回当前网络里出现过的标签，去重后排序，归档任务上的也算。详情里的候选列表用的就是它。别的网络看不到。
