# 任务

桌面应用和 Android 的「任务」页，用来排人自己的工作。它和 [Web Dashboard](/guide/dashboard) 里的收件箱不是同一页：收件箱看的是会话里派来的消息；这一页是任务卡片。Agent 通过 [需求池接口](/api/mcp-tools#需求池-任务看板) 读写的是同一批记录。字段、权限和同步方式以那一节为准，这里不重复。

也不要和[派给 Agent 的会话任务](/concepts/task-lifecycle)搞混。那一页讲的是消息任务的状态机，不是这里的卡片。

iOS 仍走 TestFlight，公开链接还没开。本页按桌面和 Android 上能点到的界面来写。

## 列表和看板

导航里的「任务」。手机在底部，展开的宽屏在左侧。

顶栏可以在「列表」和「看板」之间切换，也可以筛选、新建。看板三列是「需求池」「进行中」「完成」（英文界面是 Backlog / In progress / Done）。桌面把卡片拖到另一列；手机长按卡片打开菜单。点开卡片，在右侧详情里改。

左侧可以按「全部」「我负责的」「未分配」「按 Agent」「按节点」或项目筛选，也可以看「派发记录」。

更早的 Hub 上，描述、子任务、子需求或 Issue 绑定还不可用时，客户端会提示升级。桌面自带的本地 Hub 已经支持本页说的这些操作。

## 项目

左栏「管理项目」里新建。项目有颜色，任务卡片上会带这个标签。可以按项目筛选。

项目名最多 40 个字，不能和已有的重名。归档之后不能再选；已经挂在上面的任务仍保留这个项目。

## 子任务和子需求

这是两样东西，界面用的词不一样：

- **子任务**（英文界面是 Checklist）：挂在一张卡片上的勾选清单。可以增删，桌面可以拖动排序。卡片上显示完成进度。
- **子需求**（英文界面是 Subtasks）：另一张任务卡片，挂在当前任务下面。详情里「＋ 新建子需求」。最多 5 层。卡片显示子需求进度，也能跳回父需求。筛选里可以「只看顶层」。删掉父任务后，子需求还在，并变成顶层。

## 预计完成

可以是一整天，也可以精确到秒。时刻在界面上按你的本地时区显示；Hub 存的是 UTC。全天的任务在本地那天结束前不算逾期。详情里看得到到秒的本地时刻；有指针时，悬停也能看到。

### 到期提醒

Hub 每 10 分钟查一次没完成、没归档、设了预计完成的任务，提醒负责人和参与人（人）。打开节点提醒后，负责 Agent 也会收到一条不需要回复的消息：

- **即将到期**：全天任务明天到期，或时刻在 24 小时内。每个预计完成时间提醒一次。
- **今天到期**：今天到期且还没到。每个预计完成时间提醒一次。
- **已逾期 N 天**：每天最多一次；逾期超过 7 天不再提醒。

「今天」按东八区（Asia/Shanghai）算。任务完成、归档、清空或推迟预计完成，提醒马上停；推迟之后按新时间重新提醒。Hub 重启不会重发。

提醒出现在与负责 Agent 的会话里；没有负责 Agent，或你看不到它时，发信人是「任务提醒」。

开通时不补发：每个网络第一次被检查的那一刻记为起点，只有在这之后才逾期的任务会收到「已逾期」提醒。打开这个功能，或把网络加进白名单，都不会把以前的逾期任务一次性提醒一遍。

运维可以用环境变量调整：

- `COMMHUB_DUE_REMINDERS=0`：关闭。
- `COMMHUB_DUE_REMINDER_NETWORKS=<网络 id,网络 id>`：只提醒这些网络。不设就是所有网络。
- `COMMHUB_DUE_REMINDER_NODES=1`：也给负责 Agent 发消息。默认不发，只提醒人。
- `COMMHUB_DUE_REMINDER_TICK_MS`：检查间隔。
- `COMMHUB_DUE_REMINDER_TZ`：时区。
- `COMMHUB_DUE_OVERDUE_MAX_DAYS`：逾期提醒的天数上限。

Agent 用 `requirements_list` 查到期任务：`overdue: true` 只列逾期的，`due_within_days: N` 列今天到 N 天后到期、还没逾期的（0 = 今天）。两者都只看没完成的任务。REST 列表用同名参数（`overdue=1`、`due_within_days=N`）。

## GitHub Issue

详情里「＋ 绑定 Issue」。粘贴 Issue 链接，或写成 `owner/repo#123`（编号 1–10000000）。可以绑多个，最多手动绑 8 个，绑定和解绑马上保存。卡片和列表上显示关联数量，点一下在浏览器打开。

从 GitHub 同步进来的那条来源标着「同步来源」，不能在这里解绑。同一个 Issue 不能绑两次。

给 Agent 做幂等同步时用 `external_ref`（形如 `github:owner/repo#123`），见 [需求池 / 任务看板](/api/mcp-tools#需求池-任务看板)。
