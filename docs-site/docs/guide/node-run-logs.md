# 节点运行日志

节点页里的「运行日志」看的是这个节点 agent-node 进程写在自己 `logs/` 目录里的末尾，只读。它和在节点那台机器上执行 [`anet logs`](/guide/agent-node) 不是一回事：那条命令在本机读文件。这一页是登录之后，由 Hub 向节点要一份已经脱敏的末尾。

iOS 仍走 TestFlight，公开链接还没开。本页按桌面和 Android 上能点到的界面来写。

这一区在节点页上，排在「定时任务」后面，始终显示。区标题和按钮目前是中文，不随界面语言切换。

## 打得开，但现在的节点多半还回不了

已经发布的 Hub 会接这个请求。节点要在状态里上报 `logs_capable` 才会真正回日志。发布渠道里的节点程序还没有这段，所以打开后通常看到「节点版本过旧，升级后可查看日志」，客户端不会发请求。这不是这一页坏了，要等下一版节点。

另外两种打不开：

- 状态里没有 `logs_capable` 这个字段：「服务器版本过旧，升级后可查看日志」。
- Claude Code 会话：「Claude Code 会话没有 agent-node 运行日志」。

下面是节点带上这段之后的行为。

## 谁能看

用用户账号登录。能看的是节点的所有者，以及这个网络的 owner 或 admin。其他成员和只读成员不行。用节点令牌不行。别的网络里的节点不行。

Hub 把结果交给发起这次请求的登录，读一次就删。没人来取的，五分钟后删掉。实时跟随的每一轮都是一次新请求，不会接着别人已经取走的那一份。

## 怎么看

最新的一行在最下面，打开时滚到底。错误是红色，警告是琥珀色。

- **级别**：全部、信息、警告、错误。选中的级别是精确匹配，不是「这个级别以及更严重的」。调试行只在「全部」里出现，没有单独的调试按钮。
- **搜索**：不分大小写，最多 200 个字。比的是脱敏之后的文本，搜令牌原文对不上。
- **实时跟随**：每 3 秒要一次新的末尾。应用不在前台时暂停。同一秒里再次出现的行按位置去掉。屏幕上最多留 2000 行，更早的丢掉。
- **复制**：没有行时不能点。复制的是当前屏幕上这些行。成功后短暂显示「已复制 N 行」。
- **导出 / 分享**：桌面是「导出」，文件名像 `demo-node-20260929-153045.log`（本机时区；别名里不能做文件名的字符换成下划线）。手机是「分享」。
- **刷新**：重新要一次。失败时可以重试。

桌面可以用 Ctrl+F 或 ⌘F 把光标放进搜索框。桌面可以拖选日志文字。手机上不能拖选，用复制。

匹配到的行比屏幕上显示的多时，底栏写「只显示最新的 N 行（共 M 行匹配）」。

## 节点读哪些内容

不能指定路径。节点只读自己的日志目录，不跟随里面的符号链接。有按天命名的 `YYYY-MM-DD.log` 时只取最近两天；否则取最新的一份 `start-*.log`。每个文件只读末尾 4MB。单行超过 4000 个字符会截断，并在后面标上「…(截断)」。屏幕一次要 500 行。直接调用 [MCP 工具](/api/mcp-tools) `tail_node_logs` 时最多 2000 行，再多会被拒绝；`debug` 不能当作级别参数。

离开节点之前，令牌（`ntok_`、`utok_`、`atok_`）、Bearer、Authorization，以及键名里带 token、key、secret、password 的值，会换成 `[REDACTED]`。

## 空和失败

- 还没有日志文件：「节点还没有写运行日志」。
- 有文件，但按级别或搜索筛完没有：「没有匹配的日志行」。
- 文件在，里面没有行：「日志是空的」。
- 节点没有回应：「节点没有响应（可能离线）」。
- 节点读失败：后面带上节点给的原因。
- 权限不够、要用用户账号、节点不在这个网络、服务器上没有这个节点：各有一句说明，不会改成一份空日志。
