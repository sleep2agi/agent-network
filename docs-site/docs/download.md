# 下载 Agent Network

桌面和手机客户端连接同一个 Hub。优先选择 macOS、Windows 或 Android，安装前核对架构。桌面包来自 [agent-network-app](https://github.com/sleep2agi/agent-network-app/releases) 最新正式发布的 `desktop-v*`；Android 读取独立发布渠道，并展示自己的版本和校验文件。缺少安装包的平台不会生成下载按钮。

命令行安装 `anet` 不在这里，见[安装](/guide/install)。
