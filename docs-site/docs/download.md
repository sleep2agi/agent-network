# 下载 Agent Network

桌面和手机客户端跟同一份应用，连的是同一个 Hub。这一页读取 [agent-network-app](https://github.com/sleep2agi/agent-network-app/releases) 上**最新已发布**的 `desktop-v*` 版本（和软件更新用的是同一次选择），再按文件名对上各平台的安装包。某个平台这次没有产物时，那一栏会说明，不会继续指向旧文件。

命令行安装 `anet` 不在这里，见[安装](/guide/install)。
