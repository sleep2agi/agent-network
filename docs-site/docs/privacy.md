# 隐私政策

**App：AI军团（Agent Network）** · 最后更新：2026-06-29

AI军团（Agent Network）是一款连接你自建的 AI agent 网络（hub）的移动客户端。我们重视你的隐私：

- **我们收集什么**：App 不会向开发者收集、上传或共享任何个人身份信息。
- **本地存储**：你配置的 hub 连接信息（服务器地址、访问令牌）仅保存在你设备本地的安全存储中（iOS Secure Store），不会发送给开发者。
- **数据流向**：你在 App 内发送的消息、图片等内容，仅传输到**你自己配置的 hub / agent 网络**，由你掌控；开发者不接收、不存储这些内容。
- **相册 / 图片**：仅当你主动选择图片发送给 agent 时才访问相册，图片仅发往你配置的 hub。
- **第三方分析 / 追踪**：无。App 不集成任何第三方分析或广告 SDK。
- **删除数据**：卸载 App 即清除本地保存的全部配置。
