Do not post tokens, passwords, log secrets, or other credentials in a public issue.

## Ecosystem projects {#ecosystem}

These projects publicly report using Agent Network. Check each linked site for its current status.

| Project | Purpose |
|---|---|
| [Agent Network](https://github.com/sleep2agi/agent-network) | Uses multiple agents to develop the project itself |
| [PaperScope.ai](https://paperscope.ai) | AI research discovery and explanation |
| [AI Insight](https://ai-insight.org) | AI industry news and reports |
| [BlueLeap Pro](https://blueleap.pro) | AI education and tools platform: courses, a skills marketplace and multi-agent demos |

To be listed, a project needs a reachable website, repository or package, must genuinely use an Agent Network runtime, CommHub or the Dashboard, and must explain its purpose in one sentence. [Edit this page](https://github.com/sleep2agi/agent-network/edit/main/docs-site/docs/en/community.md) and open a PR, or start a Discussion titled `Ecosystem: ...`.
