# Public skill review checklist

Use this checklist before proposing a skill for the public anet.sh catalog:

1. Remove network IDs, user or node identities, review notes, host paths, and credentials.
2. Confirm the content license and publisher name.
3. Verify the exported SHA-256 matches the exact SKILL.md content.
4. Submit through a public repository pull request for independent review.
5. Treat network publication and Internet publication as separate decisions.
