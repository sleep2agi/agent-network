## 生态项目 {#ecosystem}

以下项目公开报告使用 Agent Network，状态以各自网站为准。

| 项目 | 用途 |
|---|---|
| [Agent Network](https://github.com/sleep2agi/agent-network) | 项目自身使用多 Agent 协作开发 |
| [PaperScope.ai](https://paperscope.ai) | AI 论文发现与解读 |
| [AI Insight](https://ai-insight.org) | AI 行业资讯与研报 |
| [蓝色跃迁 BlueLeap Pro](https://blueleap.pro) | AI 教育与工具平台：课程、技能商城与多 Agent 实战 demo |

想加入列表：项目需有可访问的网站/仓库/软件包、确实使用 Agent Network 的 runtime、CommHub 或 Dashboard，并能一句话说明用途。直接[编辑本页](https://github.com/sleep2agi/agent-network/edit/main/docs-site/docs/community.md)提 PR，或在 Discussions 发标题以 `Ecosystem:` 开头的帖子。
